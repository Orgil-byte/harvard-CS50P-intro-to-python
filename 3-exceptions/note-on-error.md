# 1. [Syntax error] is entirely on u to solve.

That means u did not followed rule of the language. Like not closing " in string, etc...

# 2. [Value error] means u tried to force 2 different value/types

Example: int(input("Number: ")) , user inputs "cat", Then this error will show up.
It can have many scenarios so if u see this error remember or look for type /value mistakes u could have made.

# 3. [Name error] will probably means that u are calling variable that is not in scope
